# Tests
- Never change, weaken, or delete an acceptance test that I wrote into a prompt or spec in order to make it pass.
  If a test and the system disagree, stop and report what the test expects, what actually happened, and the
  evidence. Wait for my decision.
- Debug scripts are temporary: delete them before reporting a task done.
- Tests are evidence, not proof of correctness. Never describe passing tests otherwise.
